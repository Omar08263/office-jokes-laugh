## The joke

> I put my out-of-office on for a meeting about my out-of-office — the calendar accepted, my manager did not.

107 characters, one line. The out-of-office loop turns twice: first the meeting about the out-of-office itself, then the calendar saying yes while the manager says no.

## Run it

```sh
node main.ts
```

Node 22 or later. No dependencies, no network. The program writes the joke to `/output/entry.txt` (created if needed).
